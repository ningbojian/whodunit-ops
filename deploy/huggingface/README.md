# Whodunit Ops

剧本杀门店的排期、拼场与预约管理助手。这是公开演示实例，使用合成演示数据，不含真实门店信息。

## 怎么进入

1. 打开页面的登录地址，填写邮箱和称呼并提交
2. 站点会向站点所有者发送一封审批邮件；所有者批准后，申请者获得限时访问
3. 访问到期后需要重新申请

审批是人工的，**所有者不在线时无法进入**。这是刻意设计：这个版本面向单店私有部署，不做开放注册。

## 能做什么

- 场次排期看板：查看未来场次、缺位与待分配
- 预约与拼场：登记预约、补齐未分配、生成优化方案（改动前给出差异供人工确认）
- 剧本与 DM 资源管理、调休登记
- 公共剧本库检索（按人数、时长、类型筛选）
- 对话式操作：用自然语言查询和修改门店数据

## 技术说明

- 后端 FastAPI + LangGraph，模型为 DeepSeek
- 数据存 Neon Postgres，按邮箱哈希分租户隔离
- 单进程运行（对话记忆保存在进程内），进程重启会丢失对话历史，业务数据不丢
- 免费实例在无访问时会休眠，首次打开可能需要等待冷启动
